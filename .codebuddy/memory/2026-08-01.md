# 2026-08-01

## 关闭 DeepSeek v4-flash 推理（thinking）
- 背景：v4-flash 是推理模型，默认开思考（effort=high），会产生 reasoning_content / reasoning_tokens。项目评分/翻译/摘要/催化剂都是确定性结构化任务，不需要推理，reasoning_tokens 纯计费+增延迟。
- 隐藏隐患：DeepSeek 思考模式**不支持 temperature/top_p**（静默忽略不报错）——此前评分传的 temperature=0.1、摘要 0.3 一直没生效，评分实际在默认采样下跑。
- 改动：给 5 处直接构造的 payload 加 `"thinking": {"type": "disabled"}`：
  - `llm_client.py` stream_chat（摘要/催化剂，digest_service & briefing_service 间接走这里）
  - `llm_news_filter.py` `_score_batch_once` + `_translate_batch_once`
  - `catalyst_aggregator.py` `_call_ticker_mapping_llm`
  - `scripts/backfill_why.py` `_generate_why`
- `_call_llm_once` 用传入的 payload，已被上游覆盖，无需单独改。
- httpx 直接 POST JSON，thinking 放 payload 顶层即可（OpenAI SDK 才需塞 extra_body）。
- 待验证：改后看 usage 日志确认 reasoning_tokens 归零；观察一轮评分分布（temperature 恢复生效后采样行为变化）。
