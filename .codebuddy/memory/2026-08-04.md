## 事件记忆（方案B：跨周期相似事件召回）实现完成
- 背景：讨论 Reports 是否引入 mem0/hymemory。结论——不引入通用记忆层（4G 服务器跑不下 Qdrant；与 event_versions 语义重叠；与长期方案D知识图谱冲突）。改做领域化的「跨周期召回」。
- 新增/改动：
  - 新增 `backend/app/services/event_memory.py`：`EventMemoryIndex`（numpy 内存余弦）、`load_index()`、`embed_texts()`、`persist_embeddings()`、`format_memory_block()`、`cluster_query_text()`、`event_doc_text()`、`embedding_tag()`。
  - 新增迁移 `b0c1d2e3_event_embedding`（down_revision=`a9b8c7_prefilter_reason`，即原 head）：news 加 `event_embedding REAL[]` + `event_embedding_model VARCHAR(64)`，部分索引 `ix_news_event_memory`。
  - `models/news.py` 加对应两列（导入 `REAL`，`ARRAY` 原已有）。
  - `config.py` 加 `EVENT_MEMORY_*` 7 个配置项。
  - `event_synthesizer.py`：SYSTEM_PROMPT 加「历史同类事件使用规则」（禁止把历史内容写进 title/summary/latest_change，只能影响 why_important/watch_next）；`_build_user_prompt` 加 memory_block 参数（放在报道列表之前）；`_find_candidate_clusters` SQL 加 `has_embedding` 计算列（需传 `:emb_tag`）；`_synthesize_one` 返回值由 bool 改为 `dict|None`；新增 `_recall_memory()` 与 `_refresh_event_embeddings()`。
  - 新增 `backend/scripts/backfill_event_embeddings.py`（冷启动回填，BATCH_SIZE=32）。
  - 新增 `backend/tests/test_event_memory.py`（20 用例）；`test_event_synthesizer.py` 三个用例加 `ms.EVENT_MEMORY_ENABLED=False` 隔离 + `_make_cluster` 加 `has_embedding`。
- **关键设计决策**：
  - **不用 pgvector**：候选量级千级，每轮 pipeline 只加载一次索引做 numpy 矩阵乘法，避免 4G 服务器装扩展 + ivfflat 索引常驻内存。
  - **相似度区间 [0.50, 0.67)**：上界对齐 `deduplicator.EMBEDDING_CLUSTER_THRESHOLD=0.67`（≥ 该值属同一事件，由去重器负责）。曾误设 0.93，已修正——放宽上界会把同一事件当成「历史规律」误导 LLM。
  - **`event_embedding_model` 标签 = `provider/model/dim`**：切换 EMBEDDING_PROVIDER 后旧向量自动失效，无需迁移、不会异构维度比对。本地默认标签为 `siliconflow/BAAI/bge-m3/1024`。
  - 每轮 pipeline 仅新增 2 次批量 Embedding 调用（召回 query + 回写事件包）；无实质更新且已有当前模型向量则跳过回写。
  - 全部失败路径静默降级为「无记忆」，不影响合成主流程。
