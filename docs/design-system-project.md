# AlphaReader 前端设计系统 · 全量令牌化立项

> 立项时间：2026-10-11
> 触发：前端设计走查发现"令牌建了不用"，113 处硬编码色值 + 14 种圆角散值
> 目标：硬编码值收敛到设计令牌，实现单点改色、跨端一致、可维护

## 一、现状盘点（实测数据）

| 指标 | 数值 | 说明 |
|---|---|---|
| 设计令牌总数 | 80+ | App.vue 中已定义，体系完整 |
| 色值令牌引用 | 高 | `--color-text-primary` 96 次、`--color-bg-card` 50 次、`--color-brand` 36 次 |
| 圆角令牌引用 | 极低 | `--radius-md` / `--radius-pill` 各仅 1 次 |
| 硬编码色值 | 158 处（不含 App.vue） | 分布于 12 个主要文件 |
| 其中已有等价令牌 | 73 处（46.2%） | 可安全替换，渲染无变化 |
| 其中无令牌 | 85 处（53.8%） | 属令牌体系缺口 |
| 圆角散值 | 14 种 rpx + 12 种 px | 无刻度规律 |

**核心矛盾**：色值令牌用得不错（引用量大），但圆角体系形同虚设；同时存在一批"同一色值既写死又建了令牌"的重复，改主题时会漏改。

## 二、已完成的准备工作

1. **映射表**：[design-token-map.md](/Users/rick/AlphaReader/docs/design-token-map.md)
   逐值列出 158 处硬编码 → 令牌的对应关系，标注安全/需决策。

2. **替换脚本**：[tokenize.py](/Users/rick/AlphaReader/scripts/tokenize.py)
   支持 `--dry-run` 预演、`--apply` 执行、`--file` 单文件处理，自动 `.bak` 备份。

3. **令牌补齐**：App.vue 已新增 13 个缺失令牌
   `--color-danger` / `--color-success` / `--color-brand-softer` / `--color-bg-info-softer` 等，
   使可自动替换量从 70 处提升到 106 处。

## 三、执行计划（4 个批次，按风险递增）

### 批次 1：安全色值替换（106 处，零视觉风险）
- 内容：46.2% 已有等价令牌 + 新增令牌覆盖的部分
- 风险：语义等价，替换后渲染完全一致
- 验证：逐页截图 diff，重点看色值反差与 hover 态
- 命令：`python3 scripts/tokenize.py --apply`

### 批次 2：人工决策项（3 处）
- `#e8f0fe` → `--color-bg-tag` 还是 `--color-bg-info-soft`（同值双令牌，按语境定）
- `#f5f6f8` → `--color-bg-input` 还是 `--color-bg-active`
- 决策依据：该色值所在元素是输入框底还是激活态底

### 批次 3：圆角令牌化（约 130 处）
- 建立刻度：`--radius-xs(4) / sm(6) / md(8) / lg(10) / xl(12-14) / 2xl(16) / 3xl(20) / full(999)`
- 注意：现有 `--radius-*` 是 rem 单位且已被引用，**新增用独立命名**（如 `--radius-2xl`），不覆盖原令牌
- 低频散值 2/3/18/36rpx 就近收敛
- 命令：`python3 scripts/tokenize.py --apply --radius`

### 批次 4：间距与字号刻度化（可选，动静最大）
- 间距：2–24px 散值 → `--space-1~6`（已定义，待引用）
- 字号：跨断点统一见前序修复记录
- 建议：单独评估，不并入本次

## 四、风险控制

| 风险 | 应对 |
|---|---|
| 替换后色值反差下降 | 逐页截图回归，重点 hover / active / 图表 |
| rpx 与 px 令牌混用 | 移动端档用 rpx 令牌，PC 档用 px 令牌，脚本不跨档替换 |
| 圆角覆盖破坏 pill 样式 | 保留原 rem 令牌不动，新刻度用独立命名 |
| 渐变内色值遗漏 | 单独处理 `--gradient-*` 系列 |
| rgba 半透明值 | 不在本次 158 处统计内，批次 4 处理 |
| 回滚 | 脚本自动 `.bak` 备份；git 可整体回退 |

## 五、验收标准

1. `grep -rhoE "#[0-9a-fA-F]{6}\b" frontend/src --include=*.vue --include=*.css | wc -l` 显著下降（目标：除 App.vue 定义处外 < 30）
2. 圆角值收敛到 ≤ 8 种刻度值
3. 全站逐页截图与基线无视觉差异（批次 1/2 应完全一致）
4. 修改 App.vue 单令牌值，全站对应元素同步变化（验证令牌真正生效）
